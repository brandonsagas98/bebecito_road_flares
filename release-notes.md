## English

BD Road Flares v1.0.17 is free for now. Download the installation ZIP attached to this release, copy both resource folders and follow INSTALL_EN.md. The standalone core includes ESX and Qbox inventory integration, animated ignition and placement, lighting, smoke and progressive burn stages. Item definitions, icon, shop examples and bilingual installation guides are included.

OneSync is required; ox_inventory is recommended. Traffic reactions depend on GTA navigation and existing routes. See the bundled validation notes for the scope of testing. MIT license.
